人到中年，身体出现一些小状况，千万别当成小事，这可能是内脏在给我们发出提醒。

第一，多尿，是肾在提醒你。日常可以适量吃黑豆、韭菜，帮助养护肾脏。

第二，多梦，是肝在提醒你。经常睡不好、多梦，平时多吃芹菜、西兰花，清淡养肝。

第三，多屁，是肠在提醒你。肠道胀气频繁，可以吃木耳、红薯，帮助润肠通便。

第四，多痒，是肺在提醒你。皮肤莫名发痒，试试白萝卜、百合，帮助润肺。

第五，多醒，是胃在提醒你。夜里容易醒、睡不踏实，日常吃猴头菇、甘蓝，养护脾胃。

第六，多汗，是心在提醒你。动不动就出汗，菠菜、胡萝卜，有助养心。

第七，多痰，是脾在提醒你（总是痰多，山药、南瓜，健脾化痰。

![⚠️](https://static.xx.fbcdn.net/images/emoji.php/v9/tdc/1/16/26a0.png)提醒：这些只是日常食疗参考。如果症状反复、持续很久，一定要及时看医生，不要单靠食补。
